# Agente Inteligente para Organização de Tarefas

Este projeto foi desenvolvido com o objetivo de automatizar a organização de tarefas utilizando Python, integração com o Trello e inteligência artificial com Gemini.

A aplicação funciona como um assistente virtual de produtividade. Ao iniciar a conversa, o agente pergunta quais são as tarefas do dia e, conforme o usuário responde, os cards são criados automaticamente no Trello.

## Funcionalidades

* Criação automática de tarefas no Trello
* Organização das atividades por status
* Listagem de tarefas
* Atualização do andamento das atividades
* Controle de tarefas concluídas

Também é possível mover tarefas entre listas como:

* A Fazer
* Em Andamento
* Concluído

## Objetivo do projeto

A proposta deste projeto é unir automação e inteligência artificial para facilitar o gerenciamento de tarefas do dia a dia, tornando a organização mais prática e eficiente.
